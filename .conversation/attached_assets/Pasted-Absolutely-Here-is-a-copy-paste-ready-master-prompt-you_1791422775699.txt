Absolutely. Here is a **copy-paste-ready master prompt** you can use with an AI website builder or coding agent to build the complete system.

Build a complete, production-quality web application for the **University of Science and Technology of Southern Philippines (USTP) – Claveria Campus, Human Resource Management Office (HRMO)**.

The system is for the **USTP Claveria Job Order Renewal for October to December 2026**.

The goal is to replace the current long Google Form experience with a professional, official-looking, step-by-step web application while preserving the information collected by the existing form and ultimately generating an official USTP Job Order Contract.

---

# 1. CORE PRODUCT GOAL

Create a modern, highly usable, institutional HR web application with this workflow:

**Personnel**
→ Complete guided application  
→ Save progress  
→ Move between steps  
→ Review all information  
→ Edit any section  
→ Submit application  
→ Receive confirmation/reference number

**HRMO**
→ View submitted applications  
→ Review applicant information  
→ Approve/review applications  
→ Generate the official Job Order Contract  
→ Download/print the generated contract

The application must feel like an **official USTP government/university system**, not a generic SaaS dashboard.

---

# 2. DESIGN DIRECTION

Use a visual identity inspired by USTP's institutional appearance.

### Primary colors

- Deep USTP blue
- Dark navy blue
- USTP gold/yellow accent
- White
- Very light neutral gray backgrounds

Do NOT use the typical startup/SaaS appearance with excessive gradients, colorful cards, purple/blue gradients, glassmorphism, or excessive rounded corners.

The design should feel:

- Official
- Institutional
- Government/university appropriate
- Trustworthy
- Clean
- Modern
- Accessible
- Professional
- Calm
- Easy to navigate

Use restrained borders, subtle shadows, strong typography hierarchy, and generous whitespace.

# 9. VALIDATION

- Preserve everything already entered
